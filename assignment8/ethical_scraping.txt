# Task 5 Ethical Web Scraping

1.Which sections of Wikipedia are restricted for crawling?

Wikipedia's robots.txt restricts crawlers from several areas of the site. General crawlers are blocked from paths such as `/w/`, `/api/`, `/trap/`, and pages under `/wiki/Special:`. There are also additional restrictions for specific Wikipedia administrative and discussion pages. Including some deletion discussions copyright problem pages and spam-related pages.

2.Are there specific rules for certain user agents?

Yes. Wikipedia has specific rules for certain user agents. Some bots, including MJ12bot, UbiCrawler, WebCopier, HTTrack, wget, and several others, are completely blocked with `Disallow: /`. Other bots have different rules... for example, SemrushBot is given a crawl delay. Wikipedia also listed some trusted work bots that are not blocked.

3.Reflection

Websites use robots.txt to tell automated crawlers which parts of the site should or should not be accessed. Following these rules helps prevent unnecessary server load and respects the website owner's crawling policies. Ethical scraping means checking these rules before collecting data and avoiding restricted areas or overly aggressive request rates.
